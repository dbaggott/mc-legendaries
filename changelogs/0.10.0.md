**Releases now live on GitHub only.** Get the jar from
https://github.com/dbaggott/mc-legendaries/releases/latest — that link always points at the newest
release. Modrinth no longer gets new versions.

**This is a full release, not a pre-release.** Earlier versions were marked as pre-releases, which
kept them off GitHub's "latest" link. The 0.x version number is what still says the mod is early.

**Every download can be checked.** The jar and the resource pack carry a build attestation tying
them to this repository's release workflow. With the GitHub CLI:

```
gh attestation verify legendaries-0.10.0.jar --repo dbaggott/mc-legendaries
```

Nothing in the game changed: same jar for Minecraft 26.1 through the 26.3 line, and still nothing
for other players to install.
