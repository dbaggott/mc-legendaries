**The legendaries have names now.** A netherite pickaxe that is *the* Legendary Pickaxe no longer
sits in your inventory looking exactly like the one you made this morning: five of the six carry a
name of their own — the **Legendary Spear**, **Legendary Mace**, **Legendary Pickaxe**, **Legendary
Sword** and **Legendary Axe** — written in a gradient of the same molten amber the textures set into
the metal, deep at the first letter and bright at the last.

**The Dragon Egg keeps the vanilla name.** It is the one legendary you can never mistake for
something else, because there has only ever been one dragon egg.

**The name needs no resource pack.** It is an ordinary vanilla component, so it reaches every client
with nothing installed — unlike the textures, which are still an optional pack.

**A legendary you crafted before this has no name.** An item's components are fixed when it is made
and the name is written by the recipe, so it rides on the ones made from here on; putting an old one
on the pedestal and taking it back does not add one either.

**The world hears when one arrives.** The first time a legendary is in anybody's hands, the server
announces it to everyone:

```
The Legendary Pickaxe has been crafted by Steve
The Dragon Egg has been obtained by Alex
```

Once per world, not once per player — it marks the legendary arriving, not somebody acquiring it, so
handing it over, dying with it and claiming it back off the pedestal are all silent. A legendary your
world already had is announced the first time somebody picks it up after updating, since nothing
recorded the arrival at the time.

**The Netherite Spear is now the Legendary Spear, and the Mace the Legendary Mace**, in the mod's
messages as well as on the item. Nothing about either changed — the spear is still the only spear
you can get, still crafted from the same nine things, and the mace recipe is still vanilla's.

**Molten Blast's countdown** is written in the deep end of that same amber, where it was a lighter
orange of its own.

**Trying to put the Dragon Egg down** now says `The Dragon Egg cannot be placed.` rather than the
longer "will not be set down as a block".

**For operators:** every legendary answers to the name the item itself carries — `legendary_pickaxe`,
`legendary_spear`, and `dragon_egg` for the one that keeps vanilla's. That is what `item give`,
`item delete` and `config` take, and what they tab-complete.

Still one jar for Minecraft 26.1 through the 26.3 line, and still nothing for other players to
install.
